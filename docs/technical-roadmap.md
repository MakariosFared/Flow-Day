# Technical roadmap

| Sprint | Scope |
|---|---|
| 1 Foundation | Architecture, theme/routing, Drift bootstrap, DI, domain contracts, test base. |
| 2 Tasks | Task CRUD, fixed categories, estimate/priority/energy/due/preferred-time, undo. |
| 3 Today | Timeline blocks, drag/reschedule undo, progress, focus and derived overdue. |
| 4 Brain Dump | Rule parser, categorization, 30-minute fallback, task conversion. |
| 5 Planning Engine | Ranking through Reality Check and Keep/Move suggestions. |
| 6 Insights & Release | Daily/weekly aggregates, release hardening. |
| 7 Recurring Tasks & Rollover | Daily/weekly templates, occurrence flow, rollover review. |
| 8 Notifications & Live Timeline | Local reminders and automatic timeline adjustment. |
| 9 Custom Categories | Category CRUD. |

Cloud sync, AI, exact deadlines, multi-window availability, task splitting, and advanced learning remain later scope.
