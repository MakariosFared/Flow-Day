# FlowDay — Calm Productivity UI/UX Design System & Prototypes

تم تصميم واجهات وتجربة مستخدم تطبيق **FlowDay** كاملة كمنتج حقيقي موجه للمطورين وأصحاب المسؤوليات المتعددة، مبني على فلسفة **Calm Productivity** (إنتاجية هادئة، واقعية، ومرنة بعيدة عن الضغط وجلد الذات).

---

## 📁 محتويات مجلد التصميم (`ui_design/`)

1. **`index.html`**:
   - نموذج تفاعلي كامل (Interactive Prototype) يعمل مباشرة في أي متصفح بدون تثبيت أي خادم.
   - يدعم التبديل الحي بين:
     - **محاكي الهاتف التفاعلي (Mobile Device Frame)** مع Dynamic Island، Status Bar، وBottom Nav.
     - **معرض الشاشات الكامل (Grid Showcase View)** لعرض جميع الشاشات جنباً إلى جنب مثل Figma و Behance.
     - **دعم كامل للغتين العربية (RTL) والإنجليزية (LTR)** مع قلب المحاذاة والخطوط المتناسقة.
     - **المظهر النهاري الهادئ (Light) والمظهر الليلي (Dark)**.
     - عداد تركيز تفاعلي حي، وتفاعل إضافة المهام والتفريغ الذهني.

2. **مجلد الصور الجاهزة للتنفيذ (`screens_images/`)**:
   جميع الشاشات تم تصديرها بدقة عالية (High Resolution PNG) لتسهيل مراجعتها ونقلها مباشرة إلى أكواد Flutter:
   - `00_full_showcase_overview.png` — نظرة عامة على جميع الشاشات.
   - `01_onboarding.png` — شاشة الترحيب والقيمة (Onboarding).
   - `02_authentication.png` — تسجيل الدخول وإنشاء الحساب.
   - `03_today_dashboard.png` — لوحة اليوم الرئيسية (Today Dashboard).
   - `04_brain_dump.png` — شاشة التفريغ الذهني السريع (Brain Dump).
   - `05_create_task.png` — شاشة إنشاء وتعديل المهمة مع كاشف التعارض الزمني.
   - `06_task_details.png` — تفاصيل المهمة والوقت الفعلي مقابل المقدر.
   - `07_tasks_list.png` — إدارة وتصفية جميع المهام (All, Inbox, Upcoming, Completed).
   - `08_day_planner.png` — مخطط اليوم والجدول الزمني الواقعي وتوزيع فترات الراحة.
   - `09_focus_session.png` — جلسة التركيز الصامتة مع العداد الدائري الهادئ.
   - `10_insights.png` — تحليلات ومؤشرات الأداء الهادئة بدون لوم أو Toxic Streaks.
   - `11_settings.png` — إعدادات الحساب والمظهر والمزامنة السحابية Offline-First.
   - `12_design_system_components.png` — مكتبة العناصر المشتركة (Buttons, Badges, Chips, Sync States, Empty States).
